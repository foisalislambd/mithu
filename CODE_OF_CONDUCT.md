# Code of Conduct

Mithu is a public project. People who use it, report bugs, or send changes are expected to treat each other with respect.

## Expected behavior

Be clear and kind in issues, pull requests, and reviews. Disagree about the code, and leave the person alone. Assume a good reason for a question. English is the language of the product and of this repository.

## Unacceptable behavior

Insults, harassment, and sexual language aimed at another person are not accepted. Publishing someone's private information is not accepted. The same rules apply in issues, code review, and any other space maintained for this project.

## Reporting

Tell [@foisalislambd](https://github.com/foisalislambd) through a private message on GitHub, or through the address published on that profile. A security bug still goes through [SECURITY.md](SECURITY.md).

The maintainer will look at the report, may remove comments or block an account, and will reply when there is something to say.
