# Security

Mithu loads pages from the network and runs their scripts. Please report a vulnerability in private.

Use [GitHub private vulnerability reporting](https://github.com/foisalislambd/mithu/security/advisories/new) for this repository. If that page is not available yet, email the maintainer through the address on [github.com/foisalislambd](https://github.com/foisalislambd) and include the word Mithu in the subject.

Please include what you ran, the Mithu version or commit, and a page or steps that show the problem. Give the maintainer time to look at it before writing about it in public.

A public issue is fine for a crash that does not expose data or bypass the network checks. Certificate hostname verification stays enabled.
