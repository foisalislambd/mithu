# Changelog

Mithu follows the version in the workspace `Cargo.toml`. Dates are the day the release is tagged.

## Unreleased

A running script is the real `document.currentScript` element (`src` resolves, `getAttribute` works), and `DOMContentLoaded` plus `window` `load` fire after the scripts. `document.readyState` ends as `complete`. Modules link after their imports finish loading, and a relative import resolves against the module that imported it. `document.cookie` is a string, so pages can call methods on it. `performance.mark` and `performance.measure` exist. Page scripts get `URL`, `URLSearchParams`, `TextEncoder`, `TextDecoder`, `XMLHttpRequest`, `MutationObserver`, `history`, `atob`, and `btoa`. Real pages: charset detection (UTF-8 and windows-1252), `data:` documents, `@import`, `srcset`, mixed-content blocking, SameSite on subresources, a CORS check on `fetch`, `localStorage` and `sessionStorage`, script `type`/`defer`/`async`/`nomodule` ordering, `:is()` and `:where()`, table user-agent display, two-stop `linear-gradient`, and a cap on `var()` and script-driven redirect cycles. The UI thread uses a 16 MiB stack so large page scripts can run. Classic scripts are not skipped for size or cut off after a few seconds: Boa yields every 16384 opcode costs, and the window pumps each task so the frame, throbber, and throbber animation keep going. A screenshot still waits until the scripts finish. Chrome Refresh frame: tab strip, caption buttons, toolbar, omnibox chip, bookmarks bar, app menu, new tab page, tab drag, history, downloads, and settings. Toolbar glyphs are Chromium's BSD vector icons (`crates/shell/icons/NOTICE`). The network profile stores cookies (`Expires`, `SameSite`), inflates gzip, deflate, and brotli, speaks HTTP/2 when TLS negotiates it, and reuses fresh `Cache-Control: max-age` responses from memory and disk. Layout covers floats, flex shrink, and a basic grid. CSS keeps rules inside `@layer` and `@supports`, unescapes selector identifiers, and applies logical `margin`/`padding`/`inset` plus `:root` custom properties. The `[hidden]` attribute hides a subtree. HTML comments stay in the tree, and comment nodes expose `data`, `nodeType`, and sibling links so a page can move nodes around them. `self`, `performance.now`, and `requestAnimationFrame` are available to classic scripts. JavaScript remains on Boa. Inline SVG paints paths and basic shapes (`viewBox`, fill, stroke). `inline-flex` shrinks to its contents, and a nowrap flex item such as a button does not shrink below its label. Tables size columns from min- and max-content and place cells in rows, including colspan and rowspan. Text is shaped with rustybuzz, so a Bangla conjunct is one glyph, and `@font-face` loads WOFF (zlib) and WOFF2. The active tab uses the scooped path from Chromium's horizontal tab style, toolbar presses grow a ripple, and the frame follows the desktop color scheme. Page scripts get `Image`, `HTMLElement`, `Document`, `MessageChannel`, `crypto.getRandomValues`, `crypto.randomUUID`, `crypto.subtle.digest` (SHA-256), async `XMLHttpRequest`, `requestIdleCallback`, and `MutationObserver` records. `import.meta.url` is the module's URL, which is what a bundler uses for an automatic public path. `window.removeEventListener` exists, and `navigator.platform` is a string. `getBoundingClientRect`, `offsetWidth`, and `clientWidth` read the latest layout. Import maps resolve bare specifiers such as `react-dom/client`. `location` and anchor elements expose URL parts, `document.referrer` is a string, and `dataset` reads and writes `data-*` attributes. Grid items honor `grid-column` and `grid-row` line and span, `grid-template` areas, `grid-auto-flow: column`, `minmax()` tracks, and named lines. `position: sticky` pins to `top` and clamps at the containing block; `bottom` sticks within the viewport. `box-shadow` paints. A nowrap label widens its border box. Iframe `src` documents run in their own realm, then are laid out and painted inside the frame. Responses inflate zstd, and `Partitioned` cookies stay on the top-level site. See `docs/ARCHITECTURE.md`.
