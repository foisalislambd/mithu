# Changelog

Mithu follows the first line of `VERSION.md`. Dates are the day the release is tagged.

## Unreleased

## 0.2.2

The README screenshots are retaken on the Chromium-style frame, including the Servo Wikipedia page.

The Servo edition paints the page into one shared offscreen framebuffer and blits it on the window GL surface, under the browser frame. The OSMesa readback path stays for headless runs and for machines with no window GL context. Internal-page screenshots no longer wait on web fonts.

Lite finishes page loads under Xvfb again. The glib loop from 0.2.0 stays, and a wake no longer repaints the frame, which on Xvfb turned into a resize loop that never ran WebKit. A plain Xvfb with no GLX visual no longer fails window creation with `GLXBadWindow` (GTK's GL probe was sharing winit's X connection); if the window still cannot open, Lite exits non-zero. `mithu://downloads` was treated as a `mithu://do` settings command because the check was a string prefix, so that page never started; it is now a real navigation. `mithu://` pages are served by a custom scheme, and internal pages keep their URL and icon in the frame.

## 0.2.1

Windows CI and the release builds point bindgen at Clang 22 or newer, which MSVC 14.52's STL headers require on the `windows-2025-vs2026` runner. The image's LLVM 20 failed mozangle with STL1000. The release workflow no longer cancels the other platform jobs when one build fails, so a Windows failure no longer drops the macOS and Linux artifacts.

## 0.2.0

The browser frame is redrawn to match Chromium's desktop UI. Tab strip, toolbar, omnibox, bookmarks bar, menus, and bubbles use Chromium's layout metrics (40 DIP tab strip, 46 DIP toolbar, 34 DIP pill omnibox, 256 DIP tabs with an 18 DIP overlap) and its light and dark color tokens, so the dark theme now darkens the whole frame. Shapes are anti-aliased with tiny-skia, icons are Chromium's vector icons converted to SVG (`tools/icon2svg.py`), and text gets a contrast curve so it stays crisp. Tabs show the site favicon or the default globe, the New Tab page has no favicon, the profile button is a generic avatar, and the Mithu mark stays only on the window icon, the New Tab page, the About page, and the omnibox chip for internal pages. A throbber replaces the load bar.

Dependencies are refreshed: wry 0.57.3, png 0.18.1 (with the `output_buffer_size` change), url 2.5.9 and other semver-compatible lockfile bumps, `actions/setup-java` v6, `actions/checkout` v7, and `gradle/actions/setup-gradle` v6 with the MIT `cache-provider: basic`.

Painting follows a Chromium-style backend. The Servo edition reads the last painted frame instead of taking a screenshot every frame, paces paints at 60 Hz, holds the previous pixels on a tab switch, and does not paint hidden tabs. Lite uses a single glib poll for GTK and the winit fd. Wheel scrolling uses an inverse-delta smooth curve. Under memory pressure, least-recently-used background tabs are discarded. `tools/bench` compares Mithu with Chromium. See `docs/PERF.md`.

The project license is Apache-2.0. Servo stays MPL-2.0.

## 0.1.9

The Servo edition keeps the window thread off the engine. Script for each site runs in a content process, blank and internal pages stay in-process, and site processes stop at four. The chrome font book skips faces larger than 1 MB so a blank window stays under the previous idle RAM. Shutting down that in-process script thread on Windows no longer panics the constellation. Layout, network, and image work use a pool sized to the machine. Pages are stored in a small disk cache, background tabs are frozen, and the release build is optimized and stripped. See `docs/PROCESS.md`.

## 0.1.8

The phone new-tab page is generated at build time and loads the logo and fonts as files, so those copies are not stored in git.

## 0.1.7

Cut, copy, paste, and select all work in the address bar and are sent to the page. Paste and go opens the clipboard text. Copy link, create shortcut, name window, and send to devices do something visible. A site link whose address looks like a file download is saved into the downloads folder. Permission exceptions are stored per site, and the Servo edition allows or blocks the request from that choice. Tab groups have a name, a color, a collapse control, and an editor. CI builds a debug Android APK and an unsigned iOS app.

## 0.1.6

Site settings lists the common permissions and content types, each with Ask, Allow, and Block. Empty history and downloads show an illustration. Toolbar icons are filled Material paths. Save page writes the file into the downloads folder. Task manager lists the open tabs. New tab group paints a color bar on the active tab. The Servo edition sends a desktop user agent without an engine token, and Save page stores the file the same way.

## 0.1.5

New window and New private window open another process. A private window keeps its own profile. Print asks the page to print. Translate and developer tools open Mithu pages; Lite also opens the system inspector. Settings shows one section at a time, in the desktop order, and history, downloads, and bookmarks use that same page chrome.

## 0.1.4

The app menu, its submenus, the zoom row, and the page, tab, and address-bar menus follow the desktop browser order. Shortcuts stay on the row. There is no camera search and no other browser's name. New window, private window, print, translate, and developer tools stay closed until those features exist.

## 0.1.3

Shared `mithu://` pages for settings, history, downloads, bookmarks, extensions, the new tab, and the version. The frame snaps to whole pixels at 100%, 125%, 150%, and 200%. The window icon, new-tab splash, and About page use the Mithu mark: a myna over a blue globe with an orange orbit ring. The README tells his story.

## Unreleased

`MITHU_JS_DEBUG=1` records each script and, on a thrown error, appends the source text around the stack location. Boa's property and call errors in that mode also name the property or the callee. `CSSStyleDeclaration.getPropertyValue` reads inline style. `EventTarget.prototype` has the real listener methods, and `window.__shady_native_addEventListener` is that function, so a Shadow DOM polyfill can copy it. `Element.prototype` exposes `attachShadow`, attribute methods, `innerHTML`, and the insertion methods polyfills patch; `Node.prototype` exposes `replaceChild` and the tree accessors. `customElements.define` stores the constructor and sets it as the prototype of matching elements. `document.implementation.createHTMLDocument` returns a document with a document element, head, and body. An image's `width` and `height` attributes are its intrinsic size before the bitmap loads, and a shrink-to-fit box uses that max-content width, so a right-floated indicator no longer forces the tagline into a one-word column. A normal block or grid item keeps its containing width when a child overflows, so the Vector toolbar stays in its grid column. `getComputedStyle` returns used values such as `fontSize`. `navigator.mimeTypes`, `navigator.plugins`, `navigator.userAgentData`, and `screen` exist. `Array.prototype.group`, `Object.groupBy`, and `Map.groupBy` group items by a callback. A cross-origin `fetch` sends `Origin` on HTTP/1 and HTTP/2 and treats default ports as the same origin; `mode: "no-cors"` does not reject. An inline image, video, or canvas is a replaced box, so the line and the table cell grow to the image instead of painting the next text through it. `WheelEvent`, `MouseEvent`, and the other UI event names are constructable. A top-level `window.top`, `window.parent`, and `window.frames` are the window itself, and `frameElement` is null. Defining a custom element sets its prototype on matching nodes. `HTMLElement`'s constructor returns that node while it is upgrading, so a subclass `super()` runs on the element in the document, and `connectedCallback` runs once the node is connected. An open shadow root's children are what gets laid out, in place of the host's light DOM. `document.scripts` is the document's `<script>` elements, which `Array.from` can read. `document.readyState` is `loading` while scripts run, `interactive` when `DOMContentLoaded` fires, and `complete` when `load` fires. `customElements.whenDefined` resolves to the constructor. Prototype methods that are not also own properties of an element are non-enumerable, so `for-in` on a host object does not yield a key `getOwnPropertyDescriptor` cannot see. `Range` can be constructed and reports an empty client rect. `document.domain` is the page host, `performance.timing` exposes the navigation timestamps (including `navigationStart` and `responseStart`), `HTMLCanvasElement.getContext("2d")` returns a context that accepts drawing calls, and `initCustomEvent` sets the event type and detail. A document fragment's `insertBefore` moves a nested fragment's children, and `getElementById` returns the connected copy when a template still holds a detached node with the same id. A vendored test262 language subset (236 cases, 221 passing) and a small WPT DOM and CSS subset report their own pass rates. The misses that remain are `Intl` and `Atomics.pause`. Boa's `intl` feature needs `intl_bundled`, which embeds the ICU data blob, and that blob is not a compact data set, so it stays off. A class with no saved source text stringifies as `class { }`, so a page can tell a class from a legacy function and construct it with `Reflect.construct` instead of `Function.prototype.apply`. `structuredClone`, `Array.fromAsync`, `ArrayBuffer.prototype.transfer`, `Error.isError`, `SuppressedError`, and `Uint8Array` `toBase64` / `fromBase64` are available. A request target keeps commas and the other RFC 3986 path characters instead of rewriting them as percent-escapes. The user agent is a Chrome 157 string with `Mithu/0.1.0` appended, and `Sec-CH-UA` plus `navigator.userAgentData` name Chromium and Mithu. A cross-origin fetch also sends `Referer` as the page origin, which is what Blink sends under `strict-origin-when-cross-origin`. HTTP/3 stays off: `quinn` 0.11 plus `h3` needs a Tokio runtime and UDP stack, and the copy of Tokio already in the tree has no runtime features, so an Alt-Svc upgrade is not a small pure-Rust add-on.

`document.cookie` reads and writes non-`HttpOnly` cookies. `crypto.subtle.digest` also implements SHA-1, SHA-384, and SHA-512. `document.location` is `window.location`, `document.createEvent` returns an event whose `preventDefault` sticks, and `isConnected` reports whether a node is in the document. `document.fonts.load` resolves to a loaded face and `fonts.check` succeeds, so a page waiting on a critical font does not time out on an empty result. SVG paths honor elliptical arcs, `<use href="#id">` paints the referenced shape, and a CSS `fill` (including a custom property) colors the mark. A `float` with `width: auto` shrinks to its content, and `body` is `display: block`, so a right-floated indicator no longer squeezes the line beside it into a one-word column. `String.prototype.substr` is available. HTTP/3 is still absent: the client does not advertise `h3`. `Node.isEqualNode`, `isSameNode`, and `cloneNode` follow the DOM comparison Next uses when it diffs `<head>`, and `nonce` reflects its attribute. Linked stylesheets are loaded past the first dozen, so a later sheet can still position a menu. Text and comment nodes expose `nodeValue`, an element's `textContent` skips comments, and a `<template>` keeps its children in a document fragment so the template itself has no child nodes. `getElementById` does not see those detached nodes. A specified `height` no longer grows to fit overflowing content. `display: contents` lets the children join the parent's grid, a grid item that spans rows no longer stretches the first row, and named grid lines do not swallow the tracks after them. Media queries understand `width >=` / `width <` and `calc()`. A declaration value keeps a semicolon inside `url()` or a quoted string, and a stray `}` at the top of a sheet does not drop the rules after it, so a later sheet still applies. Rules whose subject is a class, an id, or a tag are matched from that key instead of scanning the whole sheet for every element. Ancestor compounds are rejected with a class/id/tag/attribute bloom before the tree walk, and a subject attribute selector is stored under that attribute name. `inline-size` and `min-block-size` map to width and min-height, and an empty box with `aspect-ratio` takes its height from the used width, so a hero video is not stuck at the 300×150 replaced default. A grid area name that is not in the template no longer wraps a `usize` subtraction. Negative margins are kept, and `margin-block: calc(-1 * var(--pad))` stays one length, so a padded menu button lines up with the link beside it. Anonymous classes still stringify as classes, while `attachShadow` keeps `[native code]` so a page can tell a host method from a class. Changing a text node's data notifies a `MutationObserver`, which is the microtask queue Polymer uses before it upgrades elements. `Element`, `Node`, `EventTarget`, `DocumentFragment`, `ShadowRoot`, and the common `HTML*Element` interfaces exist, and each element uses the interface for its tag so `instanceof HTMLButtonElement` matches a button. `console.info` logs. `MutationObserver` can observe `document`, including a subtree. `IntersectionObserver` reports the target as intersecting, and `ResizeObserver` reports a content box. `AbortController` and `AbortSignal` exist (`abort`, `throwIfAborted`, `AbortSignal.abort`), and `fetch` rejects when its signal is already aborted. `HTMLTemplateElement` elements expose `content`, a document fragment whose children are the template's children; `cloneNode` copies them and `appendChild` of that fragment moves the copies. `document.fonts` is a loaded font set (`ready`, `load`, `check`) and `FontFace.load` resolves, so a page does not time out waiting for a font API. Grid tracks written in `rem` or `em` resolve at 16px instead of collapsing the column. Boa's stack limit is one million slots so a large interstitial expression can finish. The page clears 52px above the status line. A running script is the real `document.currentScript` element (`src` resolves, `getAttribute` works), and `DOMContentLoaded` plus `window` `load` fire after the scripts. `document.readyState` ends as `complete`. Modules link after their imports finish loading, and a relative import resolves against the module that imported it. `document.cookie` is a string, so pages can call methods on it. `performance.mark` and `performance.measure` exist. Page scripts get `URL`, `URLSearchParams`, `TextEncoder`, `TextDecoder`, `XMLHttpRequest`, `MutationObserver`, `history`, `atob`, and `btoa`. Real pages: charset detection (UTF-8 and windows-1252), `data:` documents, `@import`, `srcset`, mixed-content blocking, SameSite on subresources, a CORS check on `fetch`, `localStorage` and `sessionStorage`, script `type`/`defer`/`async`/`nomodule` ordering, `:is()` and `:where()`, table user-agent display, two-stop `linear-gradient`, and a cap on `var()` and script-driven redirect cycles. The UI thread uses a 16 MiB stack so large page scripts can run. Classic scripts are not skipped for size or cut off after a few seconds: Boa yields every 16384 opcode costs, and the window pumps each task so the frame, throbber, and throbber animation keep going. A screenshot still waits until the scripts finish. Chrome Refresh frame: tab strip, caption buttons, toolbar, omnibox chip, bookmarks bar, app menu, new tab page, tab drag, history, downloads, and settings. Toolbar glyphs are Chromium's BSD vector icons (`crates/shell/icons/NOTICE`). The network profile stores cookies (`Expires`, `SameSite`), inflates gzip, deflate, and brotli, speaks HTTP/2 when TLS negotiates it, and reuses fresh `Cache-Control: max-age` responses from memory and disk. Layout covers floats, flex shrink, and a basic grid. CSS keeps rules inside `@layer` and `@supports`, unescapes selector identifiers, and applies logical `margin`/`padding`/`inset` plus `:root` custom properties. The `[hidden]` attribute hides a subtree. HTML comments stay in the tree, and comment nodes expose `data`, `nodeType`, and sibling links so a page can move nodes around them. `self`, `performance.now`, and `requestAnimationFrame` are available to classic scripts. JavaScript remains on Boa. Inline SVG paints paths and basic shapes (`viewBox`, fill, stroke). `inline-flex` shrinks to its contents, and a nowrap flex item such as a button does not shrink below its label. Tables size columns from min- and max-content and place cells in rows, including colspan and rowspan. Text is shaped with rustybuzz, so a Bangla conjunct is one glyph, and `@font-face` loads WOFF (zlib) and WOFF2. The active tab uses the scooped path from Chromium's horizontal tab style, toolbar presses grow a ripple, and the frame follows the desktop color scheme. Page scripts get `Image`, `HTMLElement`, `Document`, `MessageChannel`, `crypto.getRandomValues`, `crypto.randomUUID`, `crypto.subtle.digest` (SHA-256), async `XMLHttpRequest`, `requestIdleCallback`, and `MutationObserver` records. `import.meta.url` is the module's URL, which is what a bundler uses for an automatic public path. `window.removeEventListener` exists, and `navigator.platform` is a string. `getBoundingClientRect`, `offsetWidth`, and `clientWidth` read the latest layout. Import maps resolve bare specifiers such as `react-dom/client`. `location` and anchor elements expose URL parts, `document.referrer` is a string, and `dataset` reads and writes `data-*` attributes. Grid items honor `grid-column` and `grid-row` line and span, `grid-template` areas, `grid-auto-flow: column`, `minmax()` tracks, and named lines. `position: sticky` pins to `top` and clamps at the containing block; `bottom` sticks within the viewport. `box-shadow` paints. A nowrap label widens its border box. Iframe `src` documents run in their own realm, then are laid out and painted inside the frame. Responses inflate zstd, and `Partitioned` cookies stay on the top-level site. See `docs/ARCHITECTURE.md`.
