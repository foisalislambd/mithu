# Changelog

Mithu follows the version in the workspace `Cargo.toml`. Dates are the day the release is tagged.

## Unreleased

A running script is the real `document.currentScript` element (`src` resolves, `getAttribute` works), and `DOMContentLoaded` plus `window` `load` fire after the scripts. `document.readyState` ends as `complete`. Modules link after their imports finish loading, and a relative import resolves against the module that imported it. `document.cookie` is a string, so pages can call methods on it. `performance.mark` and `performance.measure` exist. Page scripts get `URL`, `URLSearchParams`, `TextEncoder`, `TextDecoder`, `XMLHttpRequest`, `MutationObserver`, `history`, `atob`, and `btoa`. Real pages: charset detection (UTF-8 and windows-1252), `data:` documents, `@import`, `srcset`, mixed-content blocking, SameSite on subresources, a CORS check on `fetch`, `localStorage` and `sessionStorage`, script `type`/`defer`/`async`/`nomodule` ordering, `:is()` and `:where()`, table user-agent display, two-stop `linear-gradient`, and a cap on `var()` and script-driven redirect cycles. The UI thread uses a 16 MiB stack so large page scripts can run, and a script bigger than 256KB is skipped so the rest of the page can paint. Chrome Refresh frame: tab strip, caption buttons, toolbar, omnibox chip, bookmarks bar, app menu, new tab page, tab drag, history, downloads, and settings. Toolbar glyphs are Chromium's BSD vector icons (`crates/shell/icons/NOTICE`). The network profile stores cookies (`Expires`, `SameSite`), inflates gzip, deflate, and brotli, speaks HTTP/2 when TLS negotiates it, and reuses fresh `Cache-Control: max-age` responses from memory and disk. Layout covers floats, flex shrink, and a basic grid. CSS keeps rules inside `@layer` and `@supports`, unescapes selector identifiers, and applies logical `margin`/`padding`/`inset` plus `:root` custom properties. The `[hidden]` attribute hides a subtree. HTML comments stay in the tree, and comment nodes expose `data`, `nodeType`, and sibling links so a page can move nodes around them. `self`, `performance.now`, and `requestAnimationFrame` are available to classic scripts. JavaScript remains on Boa. See `docs/ARCHITECTURE.md`.
